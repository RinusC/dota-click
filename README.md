# Dota Voice 🎤

Весёлая программа: управляешь героем в Dota 2 голосом.

| Говоришь | Нажимается |
|---|---|
| «первый скилл», «второй скилл», «третий скилл» | `Q`, `W`, `E` |
| «четвертый скилл», «пятый скилл» | `D`, `F` |
| «ульта» | `R` |
| «один» … «шесть» (или «первый предмет» …) | `Z` `X` `C` `V` `B` `N` |
| «телепорт» | `T` |
| «прокачать первый» … «прокачать ульту» | `Ctrl+Q` … `Ctrl+R` |
| «атака», «стоп», «держать», «герой» | `A`, `S`, `H`, `F1` |
| «голос пауза» / «голос продолжить» | временно выключить / включить голосовые команды |

Распознавание речи работает **офлайн** (модель [Vosk](https://alphacephei.com/vosk/) для русского языка, ~45 МБ):
голос никуда не отправляется, интернет нужен только для первой загрузки модели.

## Почему это не чит

Программа устроена так, чтобы не давать преимущества и не трогать игру:

- **Не лезет в игру.** Не читает и не пишет память процесса Dota 2, ничего не внедряет (никаких инжектов и DLL),
  не меняет файлы игры, не перехватывает сетевой трафик и не смотрит на экран.
- **Только обычные нажатия клавиш** через стандартную функцию Windows `SendInput` — тот же механизм,
  что у экранной клавиатуры и программ для людей с ограниченными возможностями. Для игры это неотличимо
  от того, что вы сами нажали клавишу.
- **Одна фраза = одно нажатие.** Макросов, комбо и последовательностей нет и быть не может: в `config.toml`
  у команды ровно одна клавиша (максимум с `Ctrl/Shift/Alt`, как обычная комбинация), список клавиш программа
  отклонит при запуске.
- **Никакой автоматики.** Программа ничего не делает сама: не реагирует на события в игре, не прожимает
  предметы «по таймингу», не ставит варды. Всё только по вашей команде голосом.
- **Голос медленнее пальцев.** Между концом фразы и нажатием проходит около полсекунды — это заведомо медленнее клавиатуры.
- По умолчанию клавиши нажимаются **только когда окно Dota 2 активно**, чтобы случайно не «напечатать» в чат
  Discord или браузер.

Честно: у Valve нет официального «белого списка» программ, поэтому стопроцентной гарантии не может дать никто.
Но VAC и правила Steam направлены против программ, которые вмешиваются в игру или автоматизируют действия
(скрипты, макросы, чтение памяти), — эта программа не делает ни того, ни другого. Не добавляйте в неё
последовательности нажатий и автоматические действия — тогда это перестанет быть просто «голосовой клавиатурой».

## Установка (Windows)

1. Установите [Python 3.11+](https://www.python.org/downloads/) — при установке отметьте **«Add python.exe to PATH»**.
2. Скачайте этот репозиторий (Code → Download ZIP) и распакуйте.
3. Запустите **`install.bat`** — он поставит библиотеки и скачает модель распознавания в папку `model`.
4. Запустите **`test_mic.bat`** и поговорите: программа покажет, что слышит, но клавиши нажимать не будет.
5. Запустите **`start.bat`**, зайдите в Dota 2 и играйте голосом. Выход — `Ctrl+C` в окне программы.

Если модель не скачивается автоматически, скачайте
[vosk-model-small-ru-0.22.zip](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip)
вручную и распакуйте так, чтобы получилась папка `model` с подпапками `am`, `conf`, `graph` рядом с `config.toml`.

Если вы используете точнее, но тяжелее модель `vosk-model-ru-0.42` (~1.8 ГБ) — укажите её папку в `model_path`.

### Linux / macOS

На Linux нажатия отправляются через `pynput` (нужна сессия X11), проверка активного окна там не работает.

## Настройка

Всё настраивается в **`config.toml`** (открывается Блокнотом):

```toml
[[command]]
name = "Ульта"
key = "r"
phrases = ["ульта", "ульту", "ульт", "ультимейт"]
```

- `key` — клавиша из настроек Dota 2. Если вы меняли горячие клавиши в игре, поменяйте их и здесь.
- `phrases` — какие фразы запускают команду. Можно добавлять свои синонимы.
- `[settings]` — микрофон (`device`, список — `start.bat --list-devices`), время удержания клавиши,
  проверка активного окна и т.д.

При запуске программа проверяет, знает ли модель все слова. Сленг вроде «скилл» маленькая модель может не знать —
тогда она напишет, какие фразы не будут работать; для каждой способности поэтому есть запасные варианты
(«первая способность», «первый навык»). Посмотрите, что программа пишет при старте, и оставьте те фразы,
которые лучше всего у вас распознаются.

Советы:
- Говорите коротко и чётко, после фразы — короткая пауза.
- Если программа слышит звуки игры, используйте наушники или push-to-talk-микрофон.
- Для способностей с выбором цели: скажите «первый скилл», затем кликните мышкой по цели
  (или включите «быстрое применение» в настройках игры).

## Для разработчиков

```
dota_voice/
  __main__.py    — запуск, основной цикл
  config.py      — загрузка и проверка config.toml
  recognizer.py  — микрофон + Vosk, проверка словаря, загрузка модели
  matcher.py     — разбор распознанного текста на команды
  keys.py        — отправка нажатий (SendInput на Windows, pynput на других ОС)
tests/           — тесты (python -m unittest discover -s tests -t .)
```
